# منظومة التداول والتحليل السحابي

تطبيق Node/Express مع واجهة عربية قابلة للتثبيت (PWA)، وواجهة Streamlit اختيارية. هذه الشيفرة تسجل الطلبات لمراجعة إدارية؛ لا تتصل بعقدة بلوكتشين ولا تنفذ تحويل USDT فعلياً.

## الإعداد

- `MONGODB_URI`: رابط MongoDB في متغير بيئة/مدير أسرار. لا تحفظه داخل ملفات المصدر أو Git.
- `ADMIN_PASSWORD`: كلمة مرور لوحة المشرف، تُضبط في بيئة الاستضافة ولا توضع في HTML أو JavaScript.
- `PORT`: اختياري؛ القيمة الافتراضية `10000`.

انسخ `.env.example` إلى `.env` محلياً واملأ القيم من مدير الأسرار. ملف `.env` مستثنى من Git. بما أن بيانات اتصال قاعدة البيانات القديمة كانت مضمنة في المستودع العام، يجب تدويرها وإلغاء القديمة قبل أي استخدام.

## واجهة Node

ثبّت حزم `package.json` ثم شغّل `npm start`. تعرض واجهة المستخدم على `/` و`/panel`، ولوحة المشرف على `/secure-admin-panel-2026`؛ فتح الرابط لا يمنح صلاحية إدارية، ويجب تسجيل الدخول بكلمة مرور `ADMIN_PASSWORD`. تستخدم الواجهة `window.location.origin` للاتصال بـAPI من نفس الأصل.

فحص حالة الخادم: `GET /api/health`. تظهر حالة قاعدة البيانات في الاستجابة. عند غياب الاتصال تعيد مسارات البيانات HTTP 503.

## PWA

يجب تقديم التطبيق عبر HTTPS في النشر. يتضمن `index.html` بيان التطبيق وتسجيل عامل الخدمة، وتستخدم الأيقونات المحلية `icon-192.png` و`icon-512.png`. يتجاوز عامل الخدمة طلبات `/api/` ولا يخزنها مؤقتاً.

## واجهة Streamlit الاختيارية

`app.py` واجهة منفصلة اختيارية؛ تحتاج تثبيت `requirements.txt`. إذا استضافت على أصل منفصل عن خادم Node، عيّن `API_BASE_URL` إلى أصل Node. القيمة المحلية الافتراضية هي `http://127.0.0.1:10000`.

## نقاط أمنية وتشغيلية

- اسم المستخدم وحده ليس توثيق هوية؛ لا تستخدم هذا النموذج للأموال الحقيقية قبل إضافة مصادقة مستخدمين مناسبة، وسجلات دفتر معاملات موثوقة، وضوابط امتثال ومزود دفع/حفظ مرخص.
- جلسة المشرف تحفظ في Cookie من نوع HttpOnly وSameSite=Strict، وتنتهي بعد 8 ساعات. استخدم HTTPS في بيئة الإنتاج.
- موافقة المشرف على طلب تغيّر دفتر التطبيق الداخلي فقط؛ لا تعني تنفيذ إيداع أو سحب فعلي.
